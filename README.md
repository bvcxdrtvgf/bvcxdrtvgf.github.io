# bvcxdrtvgf.github.io

## Firebaseオンライン対戦の有効化

オンライン対戦はFirebase Authenticationの匿名ログインとRealtime Databaseを使います。

1. Firebase ConsoleでAuthenticationの「匿名」ログインを有効にします。
2. Realtime Databaseを作成します。
3. このリポジトリの[`database.rules.json`](./database.rules.json)全体をRealtime Databaseの「ルール」に設定し、「公開」を押します。ポーカーは`pokerRooms`／`pokerRoomDirectory`、ブラックジャックは`blackjackRooms`／`blackjackRoomDirectory`に対戦情報と参加募集情報を保存します。最新版のルールを公開していない場合や別プロジェクト／データベースに設定した場合は`PERMISSION_DENIED`になることがあります。未認証アクセスを許可するルールには変更しないでください。
4. Authenticationの設定で、GitHub Pagesのドメインを承認済みドメインに追加します。

ソリティア対戦は6桁の部屋コードを共有して参加します。参加者一覧にプレイヤー名、選択した実績、勝利数、クリア数が表示されます。実績一覧で獲得済み実績を選ぶと、名前の横に表示できます。ホストと参加者は同じ配札を別々にプレイして先にクリアした側を勝者として表示します。オンラインでクリアすると勝利数とクリア数がそれぞれ1増えます。これはクライアント間のカジュアル対戦であり、不正な勝利報告を完全に防ぐサーバー検証はありません。

## ポーカー

スタート画面からテキサスホールデムを選び、部屋を作成するか「参加できる部屋」一覧から募集中の部屋を選びます。2〜9人で対戦でき、全員が200チップを持って開始します（SB 10 / BB 20）。チェック／コール、レイズ、フォールドを行い、チップが0になると次のハンドから脱落します。ホストが2人以上の参加者を確認して対戦を開始します。ホールカードはRealtime Databaseのプレイヤー別`private`ノードに保存し、ショーダウン時に公開します。配札と進行はホストのブラウザーが担当するため、ホストはトーナメント終了まで接続を維持してください。カードの絵柄にはソリティアで解放・選択中のキャラカードが反映されます。キャラカードの解放・切り替えはソリティアのショップでのみ行えます。

CPU戦は1対1で遊べ、難易度を選べます。CPU戦管理者モードでは、認証後に次のCPU戦の最初のハンドで役を成立させる対象（自分またはCPU）と役を選択でき、実績用の累計勝利数とCPU戦の表示勝利数も変更できます。表示勝利数は現在のCPU戦に即時反映され、次のCPU戦の開始値として保存されます。「勝利数を固定」を有効にして開始したCPU戦では、ハンド勝利数と実績用の累計勝利数が増えません。これらの設定はオンライン対戦には適用されません。

ポーカー実績はブラウザーに保存されます。参加、ショーダウンでの役完成（「綺麗に並んでいる」はストレート役で獲得）、トーナメントの敗北、累計1,000ハンド勝利、CPU全4難易度の制覇で獲得できます。部屋参加ボタンの横にある「実績」ボタンから獲得済み実績を1つ選ぶと、自分の名前の横に表示されます。オンライン対戦では選択中の実績が参加者一覧にも表示されます。

ポーカーもゲーム内チップのみのカジュアル対戦です。Firebase Realtime Databaseのクライアント主導同期のため、不正な操作や配札をサーバー側で完全に防止するものではありません。実際の金銭や価値のある賭けには使用しないでください。

## ブラックジャック

スタート画面からブラックジャックを選び、10チップ単位で賭けてディーラーと対戦します。「ヒット」でカードを引き、「スタンド」で手札を確定します。ソロCPU戦は簡単・普通・難しい・ナイトメアの難易度を選べ、難易度が高いほどディーラーが10点札やAを引きやすくなります。ディーラーに勝つと勝利数が1増え、ブラックジャックの画面に累計が表示されます。オンライン戦でもディーラーに勝ったラウンドごとに勝利数が加算され、参加者一覧にプレイヤー名、勝利数、選択中の実績が表示されます。「実績」から獲得済み実績を1つ選ぶと、オンライン一覧の名前の横に表示できます。勝利数はブラウザーに保存されます。「実績」から、ゲーム参加、最初の2枚でブラックジャック、累計10・50・100・500・1,000勝、預かり所に500・1,000・404,404,404チップを預ける全10個の実績を確認できます。実績8〜10の進捗は預かり所の現在残高で判定し、必要な枚数を預けると獲得します。Aは1または11、J・Q・Kは10として数え、ディーラーは17以上でスタンドします。通常勝利は賭け額と同額、最初の2枚のブラックジャックは賭け額の3:2の利益、引き分けは賭け額が戻ります。所持チップと預かりチップはブラウザーに保存されます。ソロ戦では預かり所にチップを保管して賭けから守り、預かりチップは最大500,000,000チップです。必要な分を5チップ単位で所持チップへ引き出せます。賭け額は従来どおり10チップ単位です。預け入れと引き出しは勝負中にはできず、オンライン対戦では預かり所を利用できません。ダブルダウン、スプリット、保険はありません。ソリティアのショップで解放・選択したキャラカードはブラックジャックのカードにも反映されます。キャラカードの解放・選択はソリティアのみで行います。

管理コード認証後の管理者モードでは勝利数、所持チップ、預かりチップを変更できます。所持チップは5枚単位、預かりチップは1枚単位（上限500,000,000枚）で設定できます。また「勝利数を固定」を有効にするとCPU戦・オンライン戦で勝利数が増えず、「自分のオンラインチップを固定」を有効にするとオンライン対戦中に自分の賭けによるチップ増減がなくなります。他の参加者のチップと順位判定には影響しません。オンライン対戦中も勝利数と固定設定を変更でき、変更した勝利数は部屋にも同期されます。オンライン中は所持・預かりチップの入力が無効になり、固定設定だけを保存できます。オンラインチップ固定の変更は次のラウンドから適用されます。各設定はブラウザーに保存されます。

ブラックジャック画面の「オンライン対戦」から部屋を作成するか、参加できる部屋一覧から選べます。1〜9人で対戦し、開始前にホストが各自の開始チップを1〜1,000枚の範囲で設定します。賭け額は1チップ単位です。全員が賭けを確定すると同時に配札され、各自がヒット／スタンドを操作し、全員の手が確定した後にホストのブラウザーがCPUディーラーを進行します。チップが1枚未満になると脱落し、脱落した順に順位が決まります。最後まで残ったプレイヤーが優勝です。ホストはトーナメント終了まで接続を維持してください。オンライン対戦はクライアント主導のカジュアル対戦であり、不正な配札や結果をサーバー側で完全に防ぐものではありません。実際の金銭や価値のある賭けには使用しないでください。
