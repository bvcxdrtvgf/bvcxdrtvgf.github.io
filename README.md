# bvcxdrtvgf.github.io

## Firebaseオンライン対戦の有効化

オンライン対戦はFirebase Authenticationの匿名ログインとRealtime Databaseを使います。

1. Firebase ConsoleでAuthenticationの「匿名」ログインを有効にします。
2. Realtime Databaseを作成します。
3. このリポジトリの[`database.rules.json`](./database.rules.json)全体をRealtime Databaseの「ルール」に設定し、「公開」を押します。ポーカー部屋は`pokerRooms/{部屋コード}/public`に作成するため、ルールを公開していない場合や別プロジェクト／データベースに設定した場合は`PERMISSION_DENIED`になります。未認証アクセスを許可するルールには変更しないでください。
4. Authenticationの設定で、GitHub Pagesのドメインを承認済みドメインに追加します。

ソリティア対戦は6桁の部屋コードを共有して参加します。ホストと参加者は同じ配札を別々にプレイし、先にクリアした側を勝者として表示します。これはクライアント間のカジュアル対戦であり、不正な勝利報告を完全に防ぐサーバー検証はありません。

## ポーカー

スタート画面からテキサスホールデムを選び、部屋を作成するか6桁のコードで参加します。2〜9人で対戦でき、全員が1,000チップを持って開始します（SB 10 / BB 20）。チェック／コール、レイズ、フォールドを行い、チップが0になると次のハンドから脱落します。ホストが2人以上の参加者を確認して対戦を開始します。ホールカードはRealtime Databaseのプレイヤー別`private`ノードに保存し、ショーダウン時に公開します。配札と進行はホストのブラウザーが担当するため、ホストはトーナメント終了まで接続を維持してください。カードの絵柄にはソリティアで解放・選択中のキャラカードが反映されます。キャラカードの解放・切り替えはソリティアのショップでのみ行えます。

ポーカーもゲーム内チップのみのカジュアル対戦です。Firebase Realtime Databaseのクライアント主導同期のため、不正な操作や配札をサーバー側で完全に防止するものではありません。実際の金銭や価値のある賭けには使用しないでください。
